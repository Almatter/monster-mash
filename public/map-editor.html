How foreground / hiding works

1. Select Foreground / hiding and choose the object, or add a foreground object.

2. Trace its visible raised silhouette with purple points, including cloth, columns and towers. This shape controls what can cover the champion; it does not block walking.

3. Drag the yellow depth line to the ground height at the object’s feet. A champion whose feet are above this line passes behind the traced silhouette. Below the line, the champion draws in front.

4. On Solid object bases, trace only the actual footprint touching the floor. Remove the base for a hanging banner so you can walk beneath it.

5. Choose Walk / hide preview, click to place a champion and use arrows, WASD or the touch pad. Behind the outline, the champion is partly visible through the scenery. Adjust the purple outline if the wrong parts disappear.

Changes stay in this editor until exported and applied to the game. Walk preview approximates the compiled collision grid; check the game after applying.
